# Text-to-Speech Synthesizer

Implementation of a speech synthesis system using Python and Coqui TTS.

## Requirements

- Google Colaboratory
- Python 3.10
- TTS 0.22.0
- IPython
- librosa 0.10.1
- matplotlib 3.8.2
- numpy 1.26.3

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Weisjan/Text-to-speech.git
   cd Text-to-speech
   ```

2. In the notebook `Train_model.ipynb`:
   - Set the output path.
   - Adjust the desired model configuration parameters.
   - Customize dataset settings in the `BaseDatasetConfig()` function.
   - Run the notebook.

3. In the notebook `Run_model.ipynb`:
   - Enter the text you want to synthesize.
   - Set the path to the trained model and configuration file, or select one of the pre-trained models.
   - Run the notebook.

4. In the notebook `mel_spectogram.ipynb`:
   - Set the path to the generated `out.wav` file.
   - Run the notebook.

## File Structure

| No | File Name              | Description                                                                 |
|----|------------------------|-----------------------------------------------------------------------------|
| 1  | `Train_model.ipynb`    | Downloads and prepares the dataset, configures and trains the model         |
| 2  | `Run_model.ipynb`      | Tests the model by synthesizing and playing back output audio               |
| 3  | `mel_spectogram.ipynb` | Generates mel spectrograms based on the synthesized output                  |
| 4  | `audio/`               | Folder containing example `.wav` files generated by the author              |
| 5  | `README.md`            | Project documentation                                                       |

## How It Works

The system sets up and downloads the LJSpeech dataset, which is used to train the text-to-speech model.  
Once the dataset is prepared, the GlowTTS model is initialized with the specified parameters, along with the audio processor and text tokenizer.

Next, training and validation samples are loaded and used to train the model. After training is complete, the trained model and configuration files are saved.

Using the trained model, the user can input text and generate synthesized speech, which can be played back directly within the IPython environment. Optionally, the user can also generate signal visualizations such as mel spectrograms for the output audio.

## Notes

The TTS model architecture can be adjusted based on project requirements. Users are encouraged to experiment with configuration parameters.  
Coqui TTS provides a wide range of customization options, enabling experimentation with various model architectures and training setups.
